Кожна цивілізація народжується двічі: спочатку непомітно, як спосіб життя, і лише потім видимо, як історія. Інтервал між цими двома народженнями — The Shadow Phase.

Every civilization is born twice: first unnoticed, as a way of life, and only then visibly, as history. The interval between these two births is The Shadow Phase.
